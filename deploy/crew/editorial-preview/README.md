# Editorial preview envelope

Execution evidence is in
[the September 8 deployment record](../../../.scratch/hackathon-launch/proofs/editorial-preview-deployment-2026-09-08.md).
The initial and first revised research attempts are preserved. The final creative preparation uses
an explicitly attributed operator primary-source supplement; it retains all previously consumed
model calls. This must not be described as fully autonomous primary-source research.

`sign-image-grant.mjs` binds this preview's allowance to one Run and at most five exact image
requests. A rejected candidate can be corrected only with a different request and a fresh exact
grant. Production retains the rejected job and counts it toward the same ceiling. No grant is
issued automatically; failed or uncertain jobs do not acquire replacement authority.

`request.json` prepares a new preview with a 50-second target estimate and at most five generated
images, as authorized on September 8. The crew chooses the Beat count, scene selection, visual
progression and useful image count. The previous milestone-2 request and delivered Run remain
historical evidence and must not be rewritten or reused to reset spending.

The new optional request fields also reach the creative roles. Production enforces
`maxGeneratedImages` before creating each new image job; existing jobs are reusable, and failed or
uncertain jobs still consume the ceiling. This limit does not replace request-bound image grants
or authorize retries. The voice configuration retains the previously accepted initial-preview
provider; it does not resolve the separate final voice/compliance work.

Before executing this request, consolidate and verify the Production and crew deployments against
the changed published contracts, then use a fresh Run and its own grants. No provider calls,
deployment, or new recording are performed by adding this configuration.

Accept the generated images against their intended composition, particularly a named detail
region. The `image_detail` capability can reframe a flattened illustration and annotate it;
`process_steps` can animate a schematic progression. Neither claims to articulate a generated
object's parts. Watch the final film with its voice before accepting the artistic result.
