# Editorial review returns to the Structurer before production

**Status:** accepted · 2026-09-08, implementing the user's instruction to improve crew creativity
while retaining the project's hard contracts.

The upstream creative envelope is a target duration in seconds and an optional maximum number of
generated images. Beat, word, scene, cut and animation counts are artistic decisions, not quotas.
Capability renderability, factual grounding, symbolic anchors, Take identity and spending authority
remain hard contracts. A duration target is an estimate, never a replacement for recorded timing.

ADR-0019's role separation remains: the Visual Structurer selects, the Scene Author fills, and
Plan Repair repairs technical refusals without changing structure. A separate Editorial Reviewer
reads the authored plan, narrative context and the selected capabilities' canonical full
specifications. It returns concrete problems and suggestions, never a rewritten plan. A rejected
draft goes back to the Structurer, then the Author, before any media production. Full specifications
remain restricted to the current selections; the Structurer still sees the compact selection tier.
Shared anchor grammar and visual vocabulary come verbatim from the published catalog.

The loop permits one structural revision and a final review. This is a model-call budget, not an
artistic quota. Technical repair has its own existing budget, shared across both drafts. Continued
editorial rejection pauses and saves the observations and terminal result; resuming that checkpoint
does not silently buy another review loop. Reopening creative work is an explicit new invocation
with a new Brief identity. Narrative Beats are immutable throughout this loop; a revision needing
new narration must return to creative preparation before recording, never silently resegment a Take.

This review judges a semantic plan. It is not evidence of watching the rendered film, hearing its
voice, or inspecting generated images. Image approval and final audiovisual review remain separate.
No universal title duration, visual-coverage percentage, or event-frequency threshold substitutes
for editorial judgement. Recorded adapters remain deterministic rehearsals without live reviews.
