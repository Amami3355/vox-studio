# Independent image work and technical film delivery

Accepted September 9, 2026. Studio retains image review and corrections, removes the final
audiovisual model review, and delivers after rendering and full video/audio decoding of the
verified MP4. New films are `ready`; historical `reviewed` evidence retains its original meaning.
Human instructions can still correct a film while preserving its recorded narration.

Each independent image has a durable checkpoint, provider journal and isolated creative context.
ADK schedules the image workflows with separate generation and review capacity (two each),
allowing generation to proceed while another candidate is reviewed. Production reserves jobs and
commits results under its Run lease, releasing that lease during the external generation call.
A correction of one image remains sequential and names the rejected candidate's exact bytes.

ADK resumability is not paid-effect authority. Stable node and operation identities reconnect
replayed activations to existing Production jobs and saved model answers. An unknown outcome
blocks further dispatch for that image. Explicit Studio continuation reconciles image evidence
before extending authorization; a worker restart does not resume unrelated saved films. Stop
prevents new dispatch and lets in-flight operations save their results. Capacity limits do not
limit total production spending.

New image bindings contain immutable content-addressed references. Image bytes are resolved and
verified at the renderer boundary, rather than duplicated through signed receipts. Historical
receipts remain untouched and readable; their verification cost remains until a separate
explicit migration design exists. A verified receipt chain is reused only within the same
lease-protected operation; later operations check integrity again.

Render progress is observational and cannot establish completion. Only the durable render result
and technical verification permit delivery. The renderer bundle is built with the container's
exact source and dependencies, with separate per-render audio directories.
