# Agent orchestration — reserved

The Director, Research (Parallel), Narrative and Visual Planner agents will live here,
built on Google ADK in Python. Nothing is initialised yet; this directory exists so the
language boundary is explicit rather than discovered later.

The boundary is already drawn by the architecture, not by this choice: agents talk to the
scene library through JSON only —

- `packages/video/src/catalog/catalog.json` — the manifest, committed, regenerated by
  `pnpm catalog`. This is everything an agent is allowed to know about the catalog.
- the four tools — `searchScenes`, `getSceneSpec`, `validateScene`, `validateVideoPlan`
  — currently plain TypeScript functions in `packages/video/src/catalog/tools.ts`. They
  get an HTTP surface when this service needs them, and not before.

No agent reads TypeScript. If the manifest is not enough to use a capability, the
manifest is what gets fixed.
